# 🍥Fuwari

A static blog template built with [Astro](https://astro.build).

This open source project is maintained solely by me.

[**🖥️Online Preview**](https://fuwari.oh1.top)

![Preview Image](https://raw.githubusercontent.com/saicaca/resource/main/fuwari/home.png)

## How to Use (Example with Netlify)
1.  [Fork this project](https://github.com/yCENzh/fuwari/fork)
2.  Use [Netlify](https://netlify.com/) to create a project -> Import existing Git repository -> Save and build (this project uses pnpm for building)
3.  That's it, very simple. For more detailed usage instructions, please visit my blog

Fuwari is an open source theme. This website serves as documentation, demonstration, and community information for the project.
